An original, deterministic Node.js renderer for a single-page summary of four verified developments reported on Tuesday, 17 November 2026. It depicts diplomacy in Manila, the Ukraine–Crimea bridge strike, measles elimination status in three countries, and Canary Islands arrivals from Africa.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program uses only Node's standard library and writes `entry.png` to the selected output directory (or `/output` in the competition sandbox). The source list and date notes are in [SOURCES.md](SOURCES.md).
